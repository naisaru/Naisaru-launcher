# Naisaru Launcher

Native Android launcher for Samsung Galaxy A55, with Liquid Glass aesthetics and a freeform DIY home screen.

## Roadmap
- App drawer with custom app groups, ordering and blur
- Freeform layout: move, rotate, resize apps and transparent image stickers
- Editable animation presets
- Widgets, icon packs, gestures, backups and themes

## Development
Kotlin, Jetpack Compose, Android SDK 35. Build using GitHub Actions or Android Studio.

> Initial scaffold under active development. Not a finished replacement for One UI Home.
